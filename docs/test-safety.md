# 测试数据安全

实机冒烟检查只读取健康状态、搜索、分页、封面、专辑及管理页。
运行时必须显式提供 `FNMUSIC_TEST_TOKEN` 与搜索关键词：

```sh
FNMUSIC_TEST_TOKEN='测试账户凭证' bash scripts/e2e_check.sh '关键词'
```

脚本不再选择数据库中最新用户凭证，也不提供实机写操作开关。
它不取音频、不收藏、不上报播放、不创建歌单，因而没有需要猜测归属并删除的音乐文件。
下载、绑定及收藏写入验证使用 `proxy/tests` 中的模拟服务和临时目录，不能改用生产实例。

不得根据歌曲名、文件名、修改时间或目录前后差异认定文件归测试所有。
历史《晴天》等归属不明文件保留，不自动删除。
如需增加下载集成测试，必须先实现独立实例、全部写入路径边界检查、创建证明及文件身份复核；
复用文件和已有业务数据不可纳入清理清单。后台任务未结束或身份变化时，保留并报告，不强制清理。

浏览列表只重试已经存在的音频文件的官方绑定，不会触发补下载。
收藏或加入歌单的显式写操作仍受收藏自动绑定开关控制；播放受边听边存开关控制。
