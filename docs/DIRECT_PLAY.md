# 播放直连（beta）与帮助弹窗

## 使用与行为

「播放与推荐 → 播放直连」提供网易盒子、musicdl、洛雪三个独立开关，
默认关闭；点击后需「保存并生效」。开关不切换主音源，也不启动预览进程。
代理监听 `.env` 后热更新；关闭配置监听的部署需重启代理。

新播放先使用可播放的本地文件和完整缓存；没有文件时，开启的音源返回
HTTPS 302。标准档 HLS、兼容清单的音频入口和 App 下载继续使用已有流程。
HEAD 返回同一目标的无正文 302，且不创建下载。

边听边存关闭时，直连请求不会新建滚动缓存或整轨保存任务。开启时，
NAS 按歌曲去重执行后台保存；因此 NAS 仍有后台音频流量。保存使用已经选定的
URL、源站请求头和编码，不重新选档。musicdl 通过受认证的短期 selection
供后台读取，沿用服务原有的下载传输实现。失效 selection 返回错误。

302 无法把 NAS 的 UA、Referer、Cookie 或 TLS 指纹设置到播放器上。
源站可能限制出口 IP、临时链接、请求头或 CORS；NAS 取链成功并不证明客户端可播。
失败时关闭对应开关并重新起播。已交付给客户端的 URL 无法撤回；
客户端直接请求 CDN 时，扩展无法感知播放失败或自动回退。

## 授权、URL 与续传

发布直链前，使用本次请求的 Cookie、Authorization、临时媒体票据或 authx
向官方 `/user/me` 确认身份。超时、异常、非成功响应、缺少用户 GUID 均失败关闭。
某类官方媒体票据如果不能通过该接口验证，也会被拒绝；其真实客户端兼容性
仍需独立实例验证。已有短期绑定的后续请求也重新验证身份。

仅交付无 userinfo、无控制字符、无歧义反斜杠的公开 HTTPS 目标；
初次和复用发布均检查 DNS 全部返回地址。禁止私网、回环、链路本地等地址。
这只是发布时检查，不能保证客户端后续 DNS 解析、多级跳转或源站行为安全。
客户端获得的只有 Location，不包含 NAS 凭据、源站请求头或内部认证头。

网易和洛雪返回剩余策略缓存寿命，代理不会把完整 TTL 从当前时间重新计算。
这些寿命是服务复用策略，并非源站保证的有效期。

短期绑定按凭证范围与歌曲隔离，容量有界。HEAD、GET 与非零 Range 复用同一
目标；后台刚落地或改写标签的本地文件不会替换这次续传。绑定失效、源配置变化
或关闭开关后，无法保证同表示的续传返回 409，需重新起播。
客户端不提供播放会话 ID，同一凭证、同一歌曲的并发播放不能完全区分。

musicdl 内部接口使用安装时生成并持久化的 `FNMUSIC_INTERNAL_TOKEN`；
容器通过启动环境传入，原生代理和服务也支持从受保护的 `.env` 读取。
凭据不属于 WebUI schema，不进入浏览器；缺失或不匹配时接口拒绝请求。
手工部署需在代理和 musicdl 两端配置同一随机凭据。

## 可复现验证与边界

离线测试入口：

```sh
python3 scripts/run_tests.py --jobs 2
python3 -m pytest -q proxy/tests/test_direct_play.py proxy/tests/test_media_url.py proxy/tests/test_direct_play_https.py
```

`test_direct_play_https.py` 生成一秒钟可解码 PCM/WAV，并使用两个不同主机名
的隔离 HTTPS 服务验证完整下载、HEAD、Range seek、跨主机跳转和过期 403。
同时覆盖依赖 UA/Referer 的 403、忽略 Range、缺失 CORS 头、多级跳转、
HTTPS→HTTP 目标拒绝、慢首字节、断流，以及同一合成音频的不同采样编码。
这些是 HTTP 客户端验证；缺失 CORS 头不代表浏览器能播放，降级跳转也不由
代理替客户端追踪或拦截，不据此宣称浏览器安全策略验收通过。
TLS 证书由测试临时生成并作为受信任证书导入客户端，保留主机名和 TLS 验证。
两个测试域名只在夹具内映射到回环地址；公开地址判定在该用例中注入，
生产 URL 校验由独立拒绝私网测试覆盖。
用例断言 NAS 响应正文为零、前台音频 opener 未调用、没有后台任务，
并核对 CDN 交付字节数。该夹具的 resolver 是模拟实现，解析和有限探活字节为零，
不能用于推断真实音乐源解析流量。
